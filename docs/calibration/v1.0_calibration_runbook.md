# v1.0 Real-World Calibration Runbook

## Goal

Validate the v1.0 ContentVerificationEngine against your actual Calibre
library on Unraid, and tune the conservative auto-apply thresholds based on
real-world distribution.

**Prerequisites**:
- Unraid host (192.168.0.122) with Calibre + this repo deployed
- A test slice of ~100 books with mixed metadata quality (some correct,
  some deliberately bad — your existing library likely has plenty)
- ~30 minutes of uninterrupted time

**Estimated time**: 30-60 minutes total (mostly waiting on the engine).

---

## Phase 1: Sanity checks (5 min)

```bash
# Verify the backend is healthy
docker compose exec app python -m bookaudit doctor

# Verify homelab host discovery works
docker compose exec app python -m bookaudit hosts

# Verify Calibre CLI is present
docker compose exec app calibredb --version

# Verify your library path
docker compose exec app ls -la /library
```

**Expected**: doctor shows Calibre CLI + Tika + Qdrant (if enabled), hosts shows
2/3 healthy (3090 + Unraid Ollama).

**If any check fails**: stop here and fix the issue. None of the calibration
below is useful without a working baseline.

---

## Phase 2: Pilot run (10 min)

Run the engine over a small slice first to validate the pipeline:

```bash
# 100 books, JSON output for easy parsing
docker compose exec app python -m bookaudit verify \
  --limit 100 --format json > /tmp/v1_pilot_100.json
```

**Expected output**: a JSON file with structure like:
```json
{
  "run_id": "verify_20260705_...",
  "elapsed_seconds": 1.2,
  "verdicts": [
    {
      "book_key": "calibre:1",
      "field_verdicts": {...},
      "overall_confidence": 99,
      "risk_flags": [],
      "action": "no_change",
      "auto_apply_eligible": false,
      "proposed_patch": {}
    },
    ...
  ]
}
```

**Quick analysis**:
```bash
# Action breakdown
python -c "
import json
data = json.load(open('/tmp/v1_pilot_100.json'))
from collections import Counter
actions = Counter(v['action'] for v in data['verdicts'])
print('Action breakdown:', dict(actions))
print('Auto-apply eligible:', sum(1 for v in data['verdicts'] if v['auto_apply_eligible']))
print('Total elapsed:', data['elapsed_seconds'], 'seconds')
"

# Flag distribution
python -c "
import json
data = json.load(open('/tmp/v1_pilot_100.json'))
from collections import Counter
flags = Counter()
for v in data['verdicts']:
    for f in v['risk_flags']:
        flags[f] += 1
print('Risk flags:', dict(flags))
"
```

**If the pilot completes in <2 seconds**: you're seeing the real
Unraid performance. ~8300 books/sec on the dev container should be
**~30,000 books/sec** on 3090.

**If it errors out**: check the JSON for `error` field. Common issues:
- Calibre library not mounted at `/library`
- LLM witness not configured (skip with `--no-llm` or set the API key)

## Phase 3: Manual accuracy check (15 min)

Pick 20 books at random from the pilot JSON and manually classify:

1. Is the `auto_apply_eligible` flag correct?
2. For `mismatch` verdicts, is the `observed_value` actually correct (i.e. extracted from the book)?
3. For `author_swap` risk flags, is the swap real?
4. For `isbn_conflict` risk flags, which ISBN is right?

Make a spreadsheet:
```
| book_key | title | action | auto_apply | actual_outcome | correct? | notes |
|----------|-------|--------|------------|-----------------|----------|-------|
| calibre:42 | Foo | suggest_fix | yes | match | yes | |
| calibre:43 | Bar | mismatch | yes | observed was wrong | NO | OCR misread "Bar" as "Baz" |
```

**Compute precision**:
```
TP = count where 'auto_apply=True' AND 'correct?=yes'
FP = count where 'auto_apply=True' AND 'correct?=no'
precision = TP / (TP + FP)
```

**Target**: precision ≥ 95%. If lower, the thresholds are too aggressive.

---

## Phase 4: Threshold tuning (10 min)

If precision < 95%, edit these constants in
`src/calibre_ai_auditor/verification/verdict.py`:

```python
# Default values; tighten if precision <95%
AUTO_APPLY_MIN_CONFIDENCE: int = 80          # raise to 85 if FPs cluster near 80
AUTO_APPLY_MIN_FIELD_CONFIDENCE: int = 75   # raise to 80 if any per-field FP > 5%
```

In `src/calibre_ai_auditor/verification/engine.py`:

```python
# In _decide_action: the action thresholds
if overall_confidence >= 85:    # was 90; lower if FPs at 85-90 range
    return VerdictAction.suggest_fix
if overall_confidence >= 70:    # was 70; tune
    return VerdictAction.needs_review
```

**Workflow**:
1. Change value
2. Re-run pilot: `docker compose exec app python -m bookaudit verify --limit 100 ...`
3. Re-classify a few books
4. Repeat until precision ≥ 95%

## Phase 5: Full library run (10 min for 10k books)

Once the pilot is well-tuned:

```bash
# Full library, JSON output for analysis
docker compose exec app python -m bookaudit verify \
  --limit 0 --format json > /tmp/v1_full.json
```

**Capture these numbers** for the BASELINE.md update:

```bash
python -c "
import json, time
data = json.load(open('/tmp/v1_full.json'))
total_books = len(data['verdicts'])
elapsed = data['elapsed_seconds']
print(f'books_per_sec: {total_books / elapsed:.1f}')
print(f'total_books: {total_books}')
print(f'elapsed_seconds: {elapsed:.2f}')

from collections import Counter
actions = Counter(v['action'] for v in data['verdicts'])
print(f'actions: {dict(actions)}')

eligible = sum(1 for v in data['verdicts'] if v['auto_apply_eligible'])
print(f'auto_apply_eligible_pct: {100 * eligible / total_books:.1f}%')

flags = Counter()
for v in data['verdicts']:
    for f in v['risk_flags']:
        flags[f] += 1
print(f'risk_flags: {dict(flags)}')
"
```

**Update `tests/benchmarks/BASELINE.md`** with the real Unraid numbers
so future PRs can detect regressions on YOUR hardware.

## Phase 6: Apply + rollback test (10 min)

Pick 5 books from the auto-apply-eligible list and apply them:

```bash
# Apply only the safe ones (auto-apply gated)
docker compose exec app python -m bookaudit apply --safe-only

# Spot-check the Calibre UI for one of the books
# Confirm: title/authors/isbn now match the book content
```

**Rollback**:
```bash
# Restore points are in .artifacts/restore/<run_id>/<book_key>/
ls /app/.artifacts/restore/

# Restore via API
curl -X POST http://localhost:8080/api/undo/<change_id> \
  -H "Content-Type: application/json" -d '{"force": true}'
```

Verify in the Calibre UI that the book reverts to its pre-fix state.

## What if something goes wrong

### Engine is too slow

- Run with `--no-llm` to skip the LLM witness entirely
- Reduce `--limit` and run in batches
- Check `bookaudit hosts` to verify the LLM is reachable

### Many false positives

- Lower the `--limit` to 10 and manually classify every result
- If a specific rule is consistently wrong, that's a bug — file an issue with
  the book details
- The 30-fixture gold-truth suite (`tests/test_verification_synthetic.py`)
  is the regression baseline; if you find new edge cases, add them there

### Many false negatives (auto-apply eligible rate too low)

- Tighten thresholds (`AUTO_APPLY_MIN_CONFIDENCE: 80` → `70`)
- Or accept the conservative posture — false negatives are safer than false positives

### OCR quality is poor on scanned books

- OCR is currently only Tesseract; PaddleOCR/Surya are behind feature flags
- For now, scanned books will be flagged for manual review (`needs_review`)
- See `docs/architecture/v1_scope_decisions.md` for comics/manga OCR work
