# Calibre Bookwarden v1.3.2

## Scope

This maintenance release aligns the public project and production interface
with the supported Certificate A boundary. The default web build now exposes
only Overview, Verify, and Review. The README includes captures of that build
with synthetic data, and the security, installation, and homelab guides explain
the stopped-library, read-only verifier and separate service roles.

It also repairs the legacy Windows cover-deck response, author suffix sorting,
SQLite read-only URI formatting, and the owner-attested canonical Gitea release
status gate. The companion `unraid-templates` repository archives its former
single-container XML because that template cannot provide Certificate A.

## Publication evidence

The source tag, a green branch pipeline, and a successful image publication are
separate checks. For this exact tag, confirm:

1. The canonical Gitea pipeline and its owner-attested GitHub status both name
   the same source commit and pass the required gates.
2. The GitHub release workflow verifies that commit and publishes the
   `release-images.json` asset with one immutable digest for each runtime
   image. OCI revision labels, scans, SBOMs, attestations, and smoke tests must
   match the release workflow's results.
3. The operator selects images by those digests, then completes the
   [production readiness](../production-readiness.md) and
   [operations](../runbooks/production-operations.md) gates in the target
   environment.

Do not substitute a mutable `1.3.2` or `1.3` tag for an image digest, or treat
publication as proof that an existing homelab stack was upgraded. The
Certificate A web/API cannot apply metadata or cover changes; a separately
reviewed writer remains outside this release's production scope.

## Known residual risk

The optional official `prom/prometheus:v3.13.3` LTS image retains the two
known HIGH gRPC findings `CVE-2026-84304` and `CVE-2026-84445`. Its narrow,
image-specific exception expires for review on 2026-10-16, or earlier if an
official fixed image is available. See
[ADR-011](../decisions/ADR-011-prometheus-lts-publication-exception.md). This
is not a claim that the monitoring image has a clean scan or that a particular
deployment is risk-free.

Certificate A still requires a consistent stopped library, a recent complete
backup with an isolated restore test, excluded external writers, private
authentication and TLS, and target-specific rollback. No one-click Unraid or
TrueNAS installer is validated for this release.
