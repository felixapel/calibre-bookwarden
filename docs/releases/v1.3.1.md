# Calibre Bookwarden v1.3.1

## Release scope

v1.3.1 is a remediation and release-evidence release. It makes the supported
Certificate A boundary explicit: local, stopped-library, read-only verification
with sealed evidence review. It does not publish an unattended writer, a
general library manager, or a one-click Unraid/TrueNAS installer.

Gitea is the canonical development and validation forge. GitHub is a public
mirror and does not mirror commits, tags, or releases automatically.

## Known risk accepted for publication

The official `prom/prometheus:v3.13.3` LTS image is pinned by OCI index digest
`sha256:6976aa8a60fec930796ce5772b8d12da7a318a5daa8d40d69c5c7819a05eeed7`.
It embeds Go 1.26.8 and gRPC 1.82.1. The image has two known HIGH findings:
`CVE-2026-84304` and `CVE-2026-84445`.

Publication accepts that narrow residual risk for the official LTS image under
the exception in [ADR-011](../decisions/ADR-011-prometheus-lts-publication-exception.md).
The exception is limited to these two findings in the Prometheus image, must be
revoked when upstream supplies a fixed official image, and must be reviewed by
2026-10-16. Loopback-only UI and an internal network reduce exposure but do not
eliminate the vulnerability risk. `CVE-2026-42154` is a separate Prometheus
pseudo-version false positive and is not evidence that the two gRPC findings
are false positives.

## Publication evidence contract

- Final v1.3.1 image digest(s) and source-revision OCI label.
- A successful automatically triggered canonical Gitea pipeline for the exact
  final release revision.
- Matching source refs on Gitea and GitHub, verified at publication time.

Use immutable digests from the final release asset manifest, never the mutable
`1.3.1` or `1.3` tags, in an operator-owned `.env`:

```dotenv
# Replace each placeholder only with the matching digest from release-images.json.
BOOKAUDIT_IMAGE=ghcr.io/felixapel/calibre-bookwarden@sha256:<certificate-a-digest>
BOOKAUDIT_EDGE_IMAGE=ghcr.io/felixapel/calibre-bookwarden-edge@sha256:<edge-digest>
BOOKAUDIT_WRITER_IMAGE=ghcr.io/felixapel/calibre-bookwarden-writer@sha256:<writer-digest>
BOOKAUDIT_RELEASE_DIGEST=sha256:<certificate-a-digest>
```

The final release workflow must produce and verify that manifest for the exact
release source before these placeholders can be filled. The writer reference is
recorded for binding consistency; it does not authorize the writer profile.

Deployment, service restarts, live-library access, and writer use require
separate operator authorization. The canonical supported deployment is the root
`docker-compose.yml` with the [Certificate A operations runbook](../runbooks/production-operations.md).
The former Unraid/TrueNAS one-click templates are archived unsupported stubs;
see [deploy/README.md](../../deploy/README.md).

## Historical claims

The v1.3.0 changelog is preserved as history. Its automatic mutation,
deployment-template, performance, test-count, and readiness claims are not
current v1.3.1 support statements. Current boundaries are ADR-003, ADR-005,
ADR-010, and ADR-011.
