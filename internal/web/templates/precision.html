Precision

What your decisions have taught Bookwarden, per fix type over all runs. A fix type is a field, the evidence path that supports it, and whether it fills an empty value or replaces one. Only a decision you made on one fix at a time, with the agents’ verdicts hidden, counts as a label. Approving, whether or not the fix was applied since, is correct; rejecting is a miss. Ticked batches, “Approve all shown”, decisions made with the verdicts shown and the agents’ own decisions never count.

Each type is judged alone: 598 labels with zero misses put the one-sided 95 % lower bound on its precision at 99.5 %. Nothing is automated yet.

Muting

A type whose decisions show poor precision is muted: its fixes leave the Fixes page’s default view and stay under the “muted types only” filter, where you can still decide them. This counts every decision you made on a fix, one at a time or in a batch, with the verdicts shown or not; each fix counts once, by your latest decision. Carried and agent decisions don’t count. Approving is correct, rejecting is a miss, and so is undoing an applied fix. A type with at least 10 decided fixes is muted when the one-sided 95 % upper bound on its precision is under 50 %. Unmuting holds until 10 more fixes of the type have been decided.
